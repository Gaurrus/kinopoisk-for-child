# AGENTS.md

## Правило версионирования

Единственный источник версии — поле `version` в `package.json`. Окно настроек
показывает её через `app.getVersion()` (`src/main/main.ts` →
`src/renderer/start/start.ts`), поэтому вручную в коде версию дублировать не нужно.

После **каждой доработки приложения** (изменение кода, конфигурации или поведения)
поднимай версию по semver `MAJOR.MINOR.PATCH`. Степень определяй сам:

- **MAJOR** — несовместимые изменения: ломается формат настроек или профиля,
  удаляется функциональность, старые данные/сборки перестают работать.
- **MINOR** — новая функциональность без нарушения совместимости: новые кнопки
  сериалов, новые режимы, новые возможности лимита.
- **PATCH** — исправления багов, мелкие правки UI/поведения и изменения сборки,
  которые не добавляют новых возможностей и не ломают совместимость.

Документация (README, AGENTS.md) без изменения поведения приложения — **без**
поднятия версии и без пересборки.

### Чек-лист после поднятия версии

1. Обновить `version` в `package.json` — это единственное место, где версия
   задаётся вручную. В `src/renderer/start/index.html` конкретную версию не
   прописывать: окно получает её через `app.getVersion()`. В `README.md`
   используй `<version>`, а не конкретное число.
2. Проверить: `yarn typecheck`, `yarn test`, `yarn build`.
3. Пересобрать и переустановить:
   - macOS:
     ```bash
     yarn dist:mac
     ditto "dist-app/mac-arm64/Kinopoisk for child.app" "/Applications/Kinopoisk for child.app"
     ```
     После установки удалить `dist-app/mac-arm64`, иначе Spotlight видит вторую
     копию приложения.
   - Windows (на Windows — `yarn dist:win`; кросс-сборка из macOS):
     ```bash
     npx electron-builder --win --x64 \
       -c.electronDist="$HOME/Library/Caches/kinopoisk-build/electron-win" \
       -c.win.signExecutable=false
     ```
     Нужен распакованный Windows-дистрибутив castLabs Electron.
4. Закоммитить изменение вместе с версией и запушить.
